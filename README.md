# Quiz Game

Course project: Kivy-based quiz game. The current application entry point is `quizgamev3.py`. The repository also includes an earlier `main.py` / `quiz.kv` version for reference.

## Run (v3)

Use a Python 3 environment with dependencies installed (for example Kivy), then:

```bash
python quizgamev3.py
```

## Run (legacy)

```bash
python main.py
```
